# Wiring on Claude Code

## Role subagents

One subagent per role, at `~/.claude/agents/tdd-{red,green,refactor}.md`.
Each file has Claude Code frontmatter plus the role contract as body.
Template: `assets/claude-code-agent-template.md`.

Green and Refactor use the same shape as the template with `src-only`
mode instead of `tests-only`, and `maxTurns: 25`.

> Duplication note: the role body is copied verbatim from
> `skills/tdd/references/roles/*.md`. This could be generated by Nix /
> home-manager so the skill's reference file remains the single source of
> truth. Manual sync until then.

## Slash command

`~/.claude/commands/tdd.md` (or a symlink into this skill's SKILL.md).
Both surfaces work: keeping SKILL.md as the single source and symlinking
avoids drift.

## Guard hook script

Shell script at `~/.claude/hooks/tdd-guard`, executable, reading Claude
Code's hook JSON from stdin. Reference implementation lives in this repo
at `scripts/tdd-guard.sh`. Install by copying (or symlinking) that file to
the hook path.

The script accepts one argument, `tests-only` or `src-only`, and reads
`.tool_input.file_path` (falling back to `.tool_input.path`) from the JSON
payload. Exit 2 blocks the write; exit 0 allows it. Adjust the
`is_test_path` patterns to match the project's layout if it differs from
the defaults.

## Verification

At session start, the orchestrator checks the hook is present and
executable. If missing, the warning goes out and the workflow proceeds
under prompt-only enforcement (see `references/guard.md`).
